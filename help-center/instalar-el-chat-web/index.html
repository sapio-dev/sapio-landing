Instalar el chat web en tu sitio

Es el canal más rápido de activar: un script en tu sitio y el agente empieza a atender a tus visitas. Sin cuentas de Meta ni verificaciones de por medio.

En resumen

Copia el script del widget desde Configuración IA → Conexión y pégalo en tu sitio antes del cierre de </body>. Las conversaciones llegan al CRM en tiempo real, con el indicador "En vivo" mientras el visitante sigue en la página.

Paso 1 — Copia el script

  1. Entra a Configuración IA → Conexión.
  2. En la sección de chat web, copia el fragmento de código del widget (un par de líneas de script con tu identificador).

Paso 2 — Pégalo en tu sitio

El script va justo antes del cierre de </body>, en todas las páginas donde quieras el chat. Según tu plataforma:

  • Sitio propio (HTML): pega el script en la plantilla base, antes de </body>.
  • WordPress: usa el editor del tema (footer.php) o un plugin para insertar código en el footer.
  • Shopify: Tienda online → Temas → Editar código → theme.liquid, antes de </body>.
  • Google Tag Manager: crea una etiqueta HTML personalizada con el script, disparada en todas las páginas.

Paso 3 — Prueba el chat

  1. Abre tu sitio en una ventana normal y en una de incógnito.
  2. Inicia una conversación como visitante: pregunta por un producto, pide un precio.
  3. Abre el CRM en el panel: la conversación aparece al instante, con el indicador "En vivo" mientras el visitante siga en la página.

Lo que conviene saber del canal

  • "En vivo": te dice que el visitante está ahora mismo en tu sitio. Es el mejor momento para intervenir tú si el caso lo amerita.
  • Cierre por inactividad: si el visitante deja de escribir, la conversación se cierra sola después de una hora. Si vuelve, parte una nueva.
  • Sin registro para el visitante: el chat no pide correo ni datos para empezar a conversar; el agente los pide en la conversación cuando corresponde (por ejemplo, para hacer seguimiento).

Preguntas frecuentes

¿El widget hace lento mi sitio?

No: el script carga de forma diferida y no bloquea el renderizado de la página. El peso es mínimo y no afecta tus Core Web Vitals.

¿Puedo instalarlo solo en algunas páginas?

Sí. El chat aparece únicamente en las páginas donde pegues el script (o donde tu gestor de etiquetas lo dispare). Muchos negocios lo ponen en todo el sitio salvo el checkout.

¿El agente del chat web es el mismo de WhatsApp?

Sí: es el mismo agente, con el mismo entrenamiento y personalidad, respondiendo en otro canal. Todas las conversaciones llegan a la misma bandeja.
